# CAD块参照批量打印PDF工具使用说明

## 一、工具简介

CAD块参照批量打印PDF工具用于自动识别 CAD 图纸模型空间中的指定图框块，并将每个图框块对应的图纸区域逐张打印为 PDF 文件，最后自动合并为一个总 PDF。

该工具适用于一份 CAD 文件中包含多张图纸图框的场景，例如施工图、设备安装图、分册图纸等。用户只需要指定 CAD 文件、图框块前缀、排序属性和导出文件夹，即可自动完成批量打印和 PDF 合并。

## 二、使用前准备

使用本工具前，请确认：

1. 当前电脑已经安装 AutoCAD2025（依赖AutoCAD接口, 其他版本AutoCAD未测试）。
2. CAD 文件格式为 `.dwg` 或 `.dxf`。
3. CAD 图纸中的图框为块参照对象。
4. 需要打印的图框块名称具有统一前缀，例如 `GEDI_TQ`。
5. 建议提前准备一个空文件夹作为 PDF 导出目录。

## 三、界面参数说明

### 1. CAD文件路径

选择需要批量打印的 CAD 文件，支持：

* `.dwg`
* `.dxf`

### 2. 块名前缀

填写需要识别并打印的图框块名称前缀。

例如：

```text
GEDI_TQ
```

工具会自动查找模型空间中所有名称以该前缀开头的块参照，并将它们作为打印图框。

### 3. 排序属性名称

填写用于排序的增强属性名称。

例如：

```text
DRAWINGNUMBER
```

如果填写该项，工具会读取每个图框块中的对应增强属性，并按属性值的字典顺序从小到大打印。

如果不填写该项，工具会按照 CAD 中识别到的默认顺序进行打印。

### 4. PDF导出文件夹

选择 PDF 文件的输出目录。

工具会将每张图纸单独导出为一个 PDF 文件，并在所有 PDF 导出完成后，在该目录下生成一个合并 PDF。

建议选择空文件夹，避免旧 PDF 被错误合并。

## 四、操作步骤

1. 打开 CraftHub。
2. 进入 CAD块参照批量打印PDF 工具页面。
3. 点击“选择CAD文件”，选择需要处理的 `.dwg` 或 `.dxf` 文件。
4. 在“块名前缀”中输入图框块名称前缀，例如 `GEDI_TQ`。
5. 在“排序属性名称”中输入排序用的增强属性名称，例如 `DRAWINGNUMBER`。如果不需要排序，可以留空。
6. 点击“选择导出文件夹”，选择一个空文件夹作为 PDF 输出目录。
7. 点击“开始打印”。
8. 等待 AutoCAD 自动打开图纸并逐张打印 PDF。
9. 打印完成后，工具会自动扫描导出文件夹内的 PDF，并合并为一个总 PDF。

## 五、输出结果

工具运行完成后，导出文件夹中会包含：

1. 每张图纸对应的单独 PDF 文件；
2. 一个合并后的总 PDF 文件。

合并 PDF 的命名规则为：

```text
原CAD文件名前缀 + merged.pdf
```

例如，原 CAD 文件名为：

```text
设备安装施工图.dwg
```

则合并 PDF 名称为：

```text
设备安装施工图merged.pdf
```

## 六、注意事项

1. 导出文件夹建议为空。
   工具会扫描导出文件夹内的所有 PDF 并进行合并，如果文件夹中存在旧 PDF，可能会被一并合并。

2. 打印过程中不要手动关闭 AutoCAD。
   工具需要通过 AutoCAD 执行批量打印任务，提前关闭 AutoCAD 可能导致打印失败。

3. 如果没有生成 PDF，请检查图框块名前缀是否正确。
   例如实际块名为 `GEDI_TQ_A3`，则块名前缀可以填写 `GEDI_TQ`。

4. 如果排序结果不正确，请检查增强属性名称是否正确。
   属性名称需要和 CAD 图框块中的增强属性标签一致，例如 `DRAWINGNUMBER`。

5. 如果不填写排序属性，工具会按默认识别顺序打印。
   这种方式不一定符合图纸编号顺序，正式出图时建议填写排序属性。

## 七、常见问题

### 1. 为什么提示导出目录非空？

因为工具会在打印完成后扫描导出目录中的所有 PDF 并合并。如果目录中已经存在 PDF，可能会影响最终合并结果。

建议新建一个空文件夹后再运行工具。

### 2. 为什么没有找到可打印图框？

通常是块名前缀填写错误，或者 CAD 中的图框不是块参照对象。

请检查：

* 图框是否为块；
* 块名是否以输入的前缀开头；
* 图框是否位于模型空间。

### 3. 为什么合并 PDF 顺序不对？

如果填写了排序属性，工具会按照该属性值排序打印。

如果未填写排序属性，则按默认识别顺序打印，顺序可能不稳定。

建议图框块中设置统一的图号属性，并在“排序属性名称”中填写该属性名。

### 4. 为什么打印出来的 PDF 有空白？

PDF 空白通常与 CAD 图框比例、纸张比例、打印窗口范围有关。工具会按照图框块外接范围打印，如果图框比例与纸张比例不完全一致，可能出现上下或左右空白。
